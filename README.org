#+TITLE: code-perf-profiler
#+AUTHOR: aygp-dr

Profile code and identify performance hotspots. Built with [[https://github.com/babashka/babashka][Babashka]].

** Quick Start

#+begin_src bash
bb run --dir ./my-project
bb run --dir ./my-project --format json
#+end_src

** Requirements

- Babashka v1.12+

** Development

This repo follows the aygp-dr Clojure standard: =deps.edn= is the canonical
manifest and =bb.edn= provides the tasks.

| Task                    | What it does                          |
|-------------------------+---------------------------------------|
| =bb test=               | JVM test suite (=clojure -M:test=)    |
| =bb test:bb=            | the same tests under babashka         |
| =bb lint=               | clj-kondo (fails on errors)           |
| =bb fmt= / =bb fmt:fix= | cljfmt check / fix                    |
| =bb check=              | lint + fmt + test + test:bb (CI runs this) |

*** Specs

Data specs live in =src/code_perf_profiler/specs.clj=, and each public fn in
=code_perf_profiler.core= has an =s/fdef= right after its =defn= (see the
[[https://clojure.org/guides/spec][clojure.spec guide]]).
=test/code_perf_profiler/specs_test.clj= runs =stest/check= over every pure fn.
The unit tests run with instrumentation on, and =clj -M:dev= instruments at the REPL.
